# Frozen evidence

`review-evidence.zip` preserves the original 148-file review package before this directory reorganization. It contains the original source paths, synthetic controls, model provenance, resource logs, aggregate historical/current results, checksums and environment snapshot. Historical medium-Paddle experiments remain separate from current Tiny results.

Use the repository's publication/ folder for the current study and docs/ for setup instructions. The archive exists for detailed review and reconstruction of the original file layout; it is not another set of current results. Raw book files, model weights and virtual environments are excluded.
